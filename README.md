# AfonsoZhang.github.io

张叔阳的中英双语个人主页，托管于 GitHub Pages：https://afonsozhang.github.io

内容包括个人介绍、研究与写作、精选项目、开源贡献、教育与经历，以及龙舟和语言学习等个人背景。最近内容更新：2026-10-28。

页面为静态 `index.html`，无需构建；`favicon.svg` 为站点图标，`assets/portrait.jpg` 沿用本人 GitHub 公开头像。中文内容在 HTML 中，英文译文在内嵌 `EN` 字典中，更新时须保持 `data-i18n` 键一致。浏览器保存语言与明暗主题偏好；默认主题跟随系统，并尊重减少动态效果设置。项目技术细节可展开阅读。

本地预览：`python3 -m http.server 8764`。推送 `main` 后由 GitHub Pages 部署。
