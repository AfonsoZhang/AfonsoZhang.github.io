# AfonsoZhang.github.io

张叔阳的中英双语研究与作品集，托管于 GitHub Pages：https://afonsozhang.github.io

内容包括 Agent 基础设施、评测与可靠性研究，工程项目、开源贡献及教育与实习经历。最近内容更新：2026-10-28。

页面为静态 `index.html`，无需构建；`favicon.svg` 为站点图标。中文内容在 HTML 中，英文译文在内嵌 `EN` 字典中，更新时须保持 `data-i18n` 键一致。浏览器保存语言偏好，并支持系统深浅色与减少动态效果设置。

本地预览：`python3 -m http.server 8764`。推送 `main` 后由 GitHub Pages 部署。
